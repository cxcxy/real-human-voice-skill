# 活人口吻 Skill

一个面向中文文案的个人写作 Skill。

它不靠替换几个“AI 高频词”来伪装人类写作，而是从沟通本身重新整理文案：谁在说、对谁说、真正想说明什么，以及读者听到这里自然会问什么。

最终目标是让文字少一点机械和过度工整，多一点真实情绪、自然语气和人的节奏，同时保证前后连贯、小白能懂，而且不突破事实与作者边界。

## 适合用来做什么

- 优化已有文案，去掉机械、工整、面面俱到的 AI 味。
- 把主题或素材写成自然的口播、文章、帖子和项目说明。
- 调整段落衔接，让下一句接住上一句留下的问题。
- 把抽象概念讲得更具体，让第一次接触话题的小白也能跟上。
- 在有依据的地方加入情绪、语气词和用户真实使用的口头语。

## 核心原则

写作的本质，是把说话者脑中的一个意思，尽量不费劲地送进读者脑中。

这个 Skill 的处理优先级是：

1. 原意、事实和边界准确。
2. 全文逻辑连贯，前后能接得住。
3. 小白能听懂、能跟上。
4. 口吻自然，有人的判断、情绪和节奏。
5. 最后才是字句漂亮。

它会主动处理假反转、万能套话、空泛拔高、整齐排比、机械总结和没有内容的转场，但不会把这些规则做成简单的违禁词表。一个表达在当前语境里真实、必要、顺口，就可以保留。

## 情绪和口头语

情绪必须来自具体事情，口头语必须有来源。

Skill 会优先复用当前原文、用户样稿、聊天原话或用户明确确认过的表达。没有个人样本时，只使用低强度的通用口语，不会擅自声称某个词是用户的习惯，也不会靠粗口、错别字、网络梗或故意结巴制造“活人感”。

## 不越界

- 不虚构作者亲历、感受、身份、关系、数据和引用。
- 不用情绪把“可能、有限、未验证”改成“肯定、绝对、已经成功”。
- 没有样本时，不擅自使用方言、粗口、攻击性称呼或强关系称呼。
- 不靠卖惨、焦虑、羞辱和挑衅换取注意力。
- 不为了顺口删除必要条件、风险提醒和事实边界。
- 不以规避 AI 检测为目标。

## 安装

使用 GitHub CLI 克隆到 Codex Skills 目录：

```bash
gh repo clone cxcxy/dayun-human-voice ~/.codex/skills/dayun-human-voice
```

如果已经克隆到其他位置，可以创建软链接：

```bash
ln -s /你的仓库路径/dayun-human-voice ~/.codex/skills/dayun-human-voice
```

安装后重新打开会话，Codex 即可识别 `$dayun-human-voice`。

## 使用方式

直接调用：

```text
使用 $dayun-human-voice 优化这段文案，保留原意和事实，写得自然一点，多一点真实情绪和我的口头语，但不要表演过头。
```

也可以描述需求后附上原文：

```text
把下面这段技术介绍改成小白听得懂的口播。不要那么工整，多一点人的语气，前后要连得上。
```

默认直接返回可使用的成稿。需要修改说明、前后对比或风格分析时，再在请求中明确提出。

## 项目结构

```text
dayun-human-voice/
├── SKILL.md
├── README.md
└── agents/
    └── openai.yaml
```

- `SKILL.md`：完整的写作原则、执行方法与边界。
- `agents/openai.yaml`：Codex 中显示的名称、简介和默认调用提示。
